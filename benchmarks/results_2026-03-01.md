# Lava.jl Benchmark Results — 2026-03-01

## Hardware
- GPU: AMD Radeon RX 7900 XTX (gfx1100, RDNA 3)
- Vulkan: 1.4.335
- ROCm: 6.4 (HIP 6.4.43484)
- CPU: (host, used for timing only)

## Software
- Julia 1.12.5
- Lava.jl (custom SPIR-V emitter, BDA arg passing)
- AMDGPU.jl 2.2.1
- GPUArrays.jl 11.4.1
- KernelAbstractions.jl 0.9.40
- AcceleratedKernels.jl 0.4.3

## Method
- 10 trials per measurement, 2-3 warmup iterations
- Timing via `@elapsed` (includes host-side dispatch + sync)
- Lava: `KA.synchronize(LavaBackend())` (vk_flush! with fence wait)
- AMDGPU: `AMDGPU.synchronize()` (HIP stream sync)
- All values in microseconds (μs), reporting median and minimum

## Analysis

### Dispatch overhead
- Lava fixed overhead: ~80-100μs per dispatch (Vulkan command buffer submit + fence wait)
- AMDGPU fixed overhead: ~30-35μs per dispatch (HIP stream API)
- Gap: ~50-70μs, dominates at small N

### Compute throughput (large N)
At 10M elements, Lava matches or beats AMDGPU on bandwidth-bound operations:
- Broadcast: **5.3x faster** (median; AMDGPU had outlier-heavy median)
- sum: **1.2x faster**
- sin+cos: **1.4x faster**
- SAXPY: **1.6x faster**
- Dot product: 2.3x slower (multi-pass reduction + CPU readback overhead)

### Key bottlenecks
1. **Dispatch overhead**: Vulkan fence-based sync (~80μs) vs HIP streams (~30μs).
   Fixable with timeline semaphores (Phase 3 optimization).
2. **Reduction multi-pass**: Each reduction pass is a separate dispatch with fence sync.
   Subgroup reductions and single-pass algorithms would help.
3. **Sort overhead at 1M**: 16.6ms includes many dispatch-flush cycles for merge passes.
   Batching merge passes into single command buffer would improve this.

## Notes
- AMDGPU 2.2.1 sort is broken on gfx1100 (RDNA 3): `hipErrorNoBinaryForGpu`.
  Confirmed in fresh Julia subprocess without Lava loaded. AcceleratedKernels
  merge sort kernel fails to produce valid ISA binary for this GPU architecture.
- AMDGPU's 10M broadcast median (3317μs) looks like an outlier; min (709μs) is more
  representative. Lava's min (626μs) still beats AMDGPU's min.
